# Dijkstra Shortest Path Visualizer

An interactive web-based project that demonstrates **Dijkstra's Single Source Shortest Path (SSSP) algorithm** using the **Greedy method**.

## 🚀 About the Project

This project visually demonstrates how Dijkstra's algorithm finds the shortest path from a selected source vertex to other vertices in a weighted graph.

It is designed to make the working of the algorithm easier to understand through an interactive web interface.

## 🧠 Algorithm

**Dijkstra's Algorithm** is a Single Source Shortest Path algorithm used to find the shortest distances from one source vertex to all other vertices in a weighted graph with non-negative edge weights.

It follows a **Greedy approach** by repeatedly selecting the unvisited vertex with the smallest known distance.

### Basic Steps

1. Select the source vertex.
2. Set the source distance to `0`.
3. Set the distance of all other vertices to infinity.
4. Select the unvisited vertex with the smallest distance.
5. Check and update the distances of its neighboring vertices.
6. Mark the selected vertex as visited.
7. Repeat the process until all vertices are processed.
8. Display the shortest paths and distances.
