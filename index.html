Single Source Shortest Path

Dijkstra's algorithm finds the shortest path from one source vertex to every other vertex in a weighted graph.

If distance[u] + weight(u,v) < distance[v], update distance[v].
⚠ Dijkstra's algorithm works only with non-negative edge weights.

How Dijkstra's Greedy Method Works

1

Initialize

Set the source vertex distance to 0. Set all other distances to infinity.

2

Select Minimum

Select the unvisited vertex having the smallest tentative distance.

3

Relax Edges

Examine all neighboring vertices and check whether a shorter path can be obtained through the current vertex.

4

Mark Visited

Mark the selected vertex as permanently processed. This is the greedy choice.

5

Repeat

Continue until all reachable vertices have been processed.

6

Construct Paths

Use the previous-vertex information to reconstruct the shortest path from the source.

Time Complexity

O(V²) Using simple array / matrix
O((V + E) log V) Using priority queue
O(V + E) Graph traversal representation
